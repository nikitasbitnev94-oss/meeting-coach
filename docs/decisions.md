# Решения, принятые при реализации

Отклонения от плана и спорные места. В скобках — чем грозит, если решение неверное.

## Влияют на поведение

1. Калибровка отклоняет ровный взгляд в сторону больше 25° («смотрели не в камеру»). Предполагается, что при взгляде в камеру MediaPipe даёт поворот головы около 0°. (Если это не так, калибровка не пройдёт никогда; видно сразу на диагностике по строке «голова yaw»; правится одним числом.)
2. Норма активной мимики: первые встречи — стартовое значение 3,0, затем медиана активности ваших встреч длиннее 5 минут. В спеке норма «калибровочная», но калибровка — спокойное лицо, на нём активность почти нулевая, и подсказка «мимика спокойнее» горела бы всегда. (Первые встречи порог условный; подстраивается в пилоте.)
3. Окно подсказок открывается отдельной кнопкой после калибровки: Chrome разрешает его только сразу после клика. (Один лишний клик.)
4. Отключённая подсказка «слово-паразит» не пишет паразиты и в отчёт.
5. «Пользователь говорит» определяется по громкости микрофона относительно фона; фон подстраивается непрерывно. (Очень длинная речь без пауз может считаться хуже.)
6. Слова-паразиты: новое слово сменяет вспышку предыдущего сразу. (Предыдущее слово может показаться меньше 2 с.)
7. Без окна подсказок анализ идёт по таймеру со страницы. (В свёрнутой вкладке Chrome замедляет таймеры — анализ реже.)
8. Если модель речи ещё грузится, когда вы нажали «Завершить», встреча сохраняется без ожидания загрузки.
9. Встреча сохраняется каждые 30 секунд; при закрытии вкладки во время встречи Chrome предупредит.
10. Режим файла: запись встаёт на паузу между калибровкой и началом; запись короче калибровки — ошибка с пояснением.
11. Отчёт называет события по-своему («Хмурость», «Руки у лица»), а не текстами подсказок.
12. Ошибки в настройках показываются с техническими именами полей (minDurationMs.hands).

## Технические

13. Время всех модулей — по часам главной страницы, у окна подсказок свои часы.
14. Частота анализа держится по сетке: при 30 Гц было 7,5 кадра/с вместо 10.
15. После пропадания лица больше чем на 1 с окно мимики начинает отсчёт заново: нет ложных «кивни» и «мимика спокойнее».
16. Модель речи (6 МБ кода) грузится только когда нужна.
17. Загрузка модели речи прерывается по ошибке или через 3 минуты: в библиотеке vosk-browser она иначе может зависнуть навсегда.
18. При завершении распознаватель дослушивает последнюю фразу (до 1,5 с).
19. Модели скачиваются при сборке на GitHub и кешируются.
20. Ошибка в тесте плана (5 с без лица проверялись на 4,9 с) исправлена в тесте.

## Отложено (мелочи)

- «Пауза вместо…» может учесть слово, которое распознаватель потом исправил. Счётчик в окне считает паразиты и при отключённой подсказке.
- Локальный режим разработки (`npm run dev`) может отдавать модель речи распакованной. Опубликованный сайт не затронут.
